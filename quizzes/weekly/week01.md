## MCQ (5 × 1)

### 1. Which STRIDE letter maps to **Authorization**?

**Answer:** d) E — Elevation of Privilege

### 2. A **trust boundary** is:

**Answer:** b) where data crosses between components of different privilege

### 3. The **attack surface** of a web page is:

**Answer:** b) every input an attacker can reach

### 4. Threat modeling is most valuable:

**Answer:** c) at design time, before code

### 5. An uploaded filename `../../etc/passwd` is an attempt at:

**Answer:** b) path traversal (information disclosure)

## Short Answer

### 6. In one sentence, what is the difference between a **use case** and a **misuse case**?

**Answer:** A use case describes how a legitimate user interacts with a system to achieve a valid goal, while a misuse case describes how an attacker or malicious user may abuse the system to achieve an undesirable outcome.
